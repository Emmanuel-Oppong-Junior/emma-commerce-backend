# Observability
Verdict: NEEDS WORK
Reviewed by: Admin/Analytics/Platform reviewer, Sonnet 5.5, medium
Files reviewed: src/commons/logger.service.ts, middlewares/logger.middleware.ts, interceptors/graphql-logging.interceptor.ts, useful-functions.ts (sanitize*), filters/all-exceptions.filter.ts, error-formatters/grapqhl-error.formatter.ts, src/tracing.ts, src/main.ts, package.json scripts, Dockerfile, src/app.controller.ts, app.service.ts, app.module.ts

## Summary
Winston logging with JSON files, but the console stream (what containers ship) is colourised plain text and files go to local disk. A request id is generated and logged, but only inside free-text messages and not propagated to service logs. GraphQL variables are logged with only `password`/`confirmPassword` masked, so tokens and customer PII reach disk. OpenTelemetry is configured but never loaded. No metrics, no error tracking.
