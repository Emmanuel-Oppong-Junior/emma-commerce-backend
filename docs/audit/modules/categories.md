# Categories
Verdict: **NEEDS WORK**
Reviewed by: Catalogue reviewer A, Claude Sonnet 5.5, default effort
Files reviewed: `src/categories/**` (service, repository, resolver, module, dto/, entities/, 3 specs; `constants/category.constants.ts` is an empty file), `src/commons/useful-functions.ts` (`extractRequestedFieldsFromQuery`), `src/commons/filters/all-exceptions.filter.ts`, `prisma/schema.prisma` (Category, SubCategory, Product), `prisma/migrations/*first_migration*` (FKs), `src/products/**` (for relation exposure), `test/e2e/category.e2e-spec.ts` (test names).

## Summary
Admin-only mutations are properly guarded, names are unique (case-insensitive check plus DB unique), and product-count protection exists on delete. Problems: the public `categories` query builds a Prisma `select` from the client's query, so an anonymous client can pull all products of every category (including inactive/draft ones) and, via relations, reviewer PII; the 5-minute category cache can never be hit; non-null `products`/`subcategories` fields are not resolved on single-category queries; deleting a category that has subcategories ends in an unmapped FK error; the name regex rejects common retail names (`Health & Beauty`, `Men's Wear`); and the flat model has no slug, ordering or active flag.

## Test assessment
Passing unit specs assert repository/service call shapes. There is no test that exercises the real query-to-select path, cache hits, or delete dependencies. E2E exists but is not runnable in the audited environment.

## Definition of done to close this module
1. `categories` returns a fixed, safe projection; `products` is no longer an unfiltered relation (CAT-01); a test asserts an anonymous client cannot fetch draft products or reviewer data through it.
2. Cache works (or is removed) and is invalidated from category and sub-category mutations (CAT-02).
3. `Category.products`/`subcategories` resolve or become nullable (CAT-03).
4. Delete checks subcategories, runs transactionally and maps FK errors (CAT-04).
5. Name validation/uniqueness fixed; `slug`, `isActive`, `sortOrder` added; public single-category query (CAT-05/06).
6. Null handling on update (CAT-07) and behavioural tests for all of the above (CAT-08).
